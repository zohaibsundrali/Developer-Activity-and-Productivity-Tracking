# DevTrack Field (Android)

Android-first workday timer and GPS review build. See [feature scope, build instructions and rollout checks](../../docs/android-field-tracking.md).

Java 17 and Android SDK 36 are required. Run `./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`.
