## Reproduced defects and repairs

| Defect | Root cause and repair | Verification |
| --- | --- | --- |
| Invalid calendar dates returned server errors or were silently discarded | Replaced regex-only date checks with strict calendar validation in Assets/Licences, Contracts/Milestones, Performance and Proposals. Optional invalid inputs now return 400 before database work. | Route-handler tests, live invalid-date requests and valid creation workflows. |
| Authorized scheduling/mobile/GitHub/presence workflows failed with permission errors | Shared billing revoked every private function grant. Restricted that migration's revoke to billing functions and restored only the guarded workflow entrypoints. Added a no-argument current-tenant lock wrapper for the invoker GitHub sync routine. | Five isolated fixture combinations, live scheduling/mobile/export, GitHub import/sync and device-presence flows; anonymous/helper privileges checked. |
| Stale updates hung rather than returning a conflict | Application conflicts used SQLSTATE `40001`, triggering indefinite retries in the connected PostgREST 14.5. Replaced explicit application conflict codes in 14 functions with `PT409`; retained genuine database serialization handling and updated API error mappings. | Live stale shifts/sites, changed mobile replay, stale GitHub link/sync and heartbeat sequence return promptly; final catalog has no explicit application `40001` raises. |
| UI offered forbidden mutations | Contracts showed manager writes/finance amendments; Recruitment showed manager administration; Performance ignored review-sharing overrides. Gated controls with the same permissions as the API. | Five browser scenarios passed, including actual equipment creation and an HR permission override denied by both API and UI. |
| GitHub issue import failed on the hosted schema | Older `developer_tasks.developer_id` was NOT NULL, contradicting the implemented unassigned-import flow. Removed only that requirement, retaining assignment FK, RLS and workflow guards. | Fixture now starts with the old constraint. Real public GitHub issue preview/import/replay passes. |
| Authorized task insertion hit a project workflow denial | Legacy invoker progress trigger changed protected project lifecycle status. Replaced it with a non-callable trigger that calculates only scoped numeric rollups, including deletes/moves, and never completes/closes projects. | Import/sync SQL and concurrency tests, lifecycle-status/rollup assertions, live task submission/rejection/approval regression. |
| 22 mutable function search paths | Pinned paths on the reviewed legacy functions while retaining their bodies, security mode and ACLs. | Advisor rerun: all 22 findings cleared. |

## Preservation and remaining limits

- Final storage check: 289 objects remain; all **288 legacy inventory records unchanged**, 43,749,177 legacy bytes preserved; normal ledger returned to one object / 781,602 bytes. Every public table has RLS. The rollup trigger is not executable by browser roles. Final cleanup read-back verified 55 recorded synthetic IDs absent. Three old QA shifts recreated by pre-fix indefinite retries were explicitly identified and removed.
- The 288 legacy files still lack authoritative organization ownership. Their records are preserved and protected; ownership was not guessed. Restoring normal tenant access/accounting for them requires a verified mapping.
- Real Stripe checkout/webhook delivery, outbound email delivery, positive platform-owner administrative flows, external AI providers and native Windows/Android hardware/background tracking were not fully exercised live. Contract/unit coverage is not equivalent to provider or device verification.
- Security advisors still flag callable security-definer helpers, extension placement and disabled leaked-password protection. Many helpers are intentionally authenticated/claim-guarded; these warnings were not blindly removed. Performance advisors still report indexing, RLS-initplan and overlapping-policy opportunities. These require separate workload/provider configuration review before a production-readiness claim.
- Browser execution used Chromium. The inventory's 1,066 controls/53 forms are discovery totals, **not** a claim that every state and interaction was clicked. Hosted deployment and post-deployment smoke testing remain outstanding.
